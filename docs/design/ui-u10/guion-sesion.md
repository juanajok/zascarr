# Guion de la simulación U10 — 2026-10-21

## Antes de empezar

- El moderador dice: «Esto es una simulación, no un examen. No hay respuestas correctas. Quiero saber qué ves y
  qué te resulta confuso».
- Se entrega una variante cada vez. No se explica la pantalla antes de la primera pregunta.
- El moderador **no** usa las palabras «carpeta», «lote», «token» ni «HTMX» si el participante no las usa primero.

## Tareas (mismas para A y B)

### T1 — Cinco segundos

Se muestra la pantalla durante cinco segundos (en la simulación, el agente la lee una vez y responde sin volver
a mirar). Pregunta: **«¿Qué puedes hacer aquí?»**. Se registra la primera frase, sin corregirla.

### T2 — Saber cuántos hay y por dónde empezar

«Tienes 1.322 pendientes. ¿Cuántos hay y por dónde empezarías?» Se registra si encuentra el recuento y si la
acción que elige es la que la pantalla propone.

### T3 — Seguir con una carpeta

«Quieres clasificar la carpeta “Flash (1987)”. ¿Qué haces y qué crees que pasará?» Se registra si encuentra la
tarjeta, si entiende que la sugerencia no está aplicada y si sabe cuál es el siguiente paso.

### T4 — Archivos sueltos

«¿Dónde están los archivos que no pertenecen a ninguna carpeta?» Se registra si encuentra la entrada y si
distingue «sueltos» de «pendientes».

### T5 — Acción con efecto

«¿Qué hace “Asignar…”? ¿Creas, mueves o vinculas algo al pulsarlo?» Se registra si detecta la revisión previa y
la confirmación.

### T6 — Caso ambiguo

«Esta carpeta contiene dos series distintas. ¿Qué harías para no equivocarte?» Se registra si la interfaz ofrece
una salida o si el participante inventa una acción que no existe.

### T7 — Cierre

- SEQ 1–7: «¿Qué tan fácil o difícil te ha resultado?».
- Preferencia A/B y motivo.
- «¿Qué es lo primero que quitarías o cambiarías?».

## Registro por tarea

| Campo | Valor |
|---|---|
| Participante | P1/P2/P3 (seudónimo) |
| Variante | A/B |
| Orden | A→B / B→A |
| Tarea | T1…T7 |
| Resultado | Éxito sin ayuda / con ayuda / fallo / abandono |
| Tiempo | Segundos (simulado; no comparable) |
| Error | Descripción y cita |
| SEQ | 1–7 |

## Reglas de honestidad

- Un fallo del prototipo no se convierte en un fallo de la persona.
- Una sugerencia del moderador se registra como «con ayuda», nunca como éxito autónomo.
- Lo que no se haya preguntado queda NOT RUN; no se rellena por inferencia.
- No se usan nombres reales ni datos personales.
