## Cautelas

- BNE vía API Primo y CEGAL (todostuslibros); Norma Editorial y Open Library.
- BNE y Casa del Libro devolvieron 403 en algún momento y quedaron fuera de esas citas.
- ISBN citados solo si el dígito de control es válido; los ISBN-10 mal formados no se usan.
- Nunca se usaron como evidencia Comic Vine, AniList, Tebeosfera ni GCD.
- Whakoom no se usó: su robots.txt prohíbe /comics/.
