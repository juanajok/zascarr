¿Qué es una serie?

Una serie es el conjunto de números de una misma publicación, por ejemplo «Flash». Una carpeta es el grupo de archivos que ZascArr cree que pertenecen a la misma serie. Elegir la serie dice a cuál se vinculan; el archivo no se mueve.
